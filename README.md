# Tech Teach

**Learn. Develop. Innovate.**

A **Tech Teach** é um projeto de tecnologia e educação sediado em **São Paulo**, que une desenvolvimento web e ensino prático. Seu lema, *Learn. Develop. Innovate.* (Aprender. Desenvolver. Inovar.), resume a proposta: aprender com base sólida, desenvolver soluções reais e inovar na forma de usar a tecnologia.

Este repositório reúne o site institucional da marca, construído com **HTML, CSS e JavaScript**.

## Valores da Tech Teach

- **Aprender:** conhecimento sólido, com explicações claras e aplicação prática.
- **Desenvolver:** projetos reais, com código bem organizado e foco no usuário.
- **Inovar:** buscar soluções novas e úteis para problemas do dia a dia.
